# Troubleshooting

This guide covers common setup and test failures for the Hardhat boilerplate.

## `circom: command not found`

`circom` is a peer tool and is not installed by `npm install`.

Verify it is on your `PATH`:

```bash
circom --version
```

Install Circom 2.x using the official Circom installation guide, then re-run:

```bash
npm run compile:circuits
```

## `Cannot find module` after cloning

Install Node dependencies from the repository root:

```bash
npm install
```

If dependency resolution looks stale, remove `node_modules` and reinstall:

```bash
rm -rf node_modules
npm install
```

## Generated verifier is missing

`contracts/verifiers/HelloHashVerifier.sol` is generated by the ZK setup step and is intentionally not committed.

Generate it with:

```bash
npm run setup:zk
```

Then compile Solidity contracts:

```bash
npm run compile
```

## Proof or zkey files are missing

The first full test run creates the trusted setup, zkey, verification key, and verifier contract.

Run:

```bash
npm test
```

If the generated artifacts are inconsistent, clean and rebuild:

```bash
npm run clean
npm test
```

## Hardhat compile fails after editing the circuit

The Solidity verifier is generated from the compiled circuit. After changing `circuits/hello_hash.circom`, regenerate the ZK artifacts before running Hardhat tests:

```bash
npm run clean
npm run compile:circuits
npm run setup:zk
npm run compile
```

## Tests skip the ZK path

The Hardhat test skips proof verification when the zkey or WASM files are missing. Run the full setup once:

```bash
npm test
```

For debugging, check that these files exist:

```text
build/hello_hash_js/hello_hash.wasm
build/hello_hash_final.zkey
contracts/verifiers/HelloHashVerifier.sol
```
