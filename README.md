# opencircom-hardhat-boilerplate

Minimal [Hardhat](https://hardhat.org/) project that compiles a Circom ZK circuit using [opencircom](https://www.npmjs.com/package/opencircom) (`^0.7.0`) and verifies a Groth16 proof on-chain.

Example circuit: prove `out = Poseidon(a, b)` and verify the proof in a deployed Solidity verifier.

## Prerequisites

- [Node.js](https://nodejs.org/) (v18+)
- [circom](https://docs.circom.io/getting-started/installation) 2.x

## Quick start

```bash
git clone https://github.com/jose-compu/opencircom-hardhat-boilerplate.git
cd opencircom-hardhat-boilerplate
npm install
npm test
```

## Commands

| Command | Description |
|--------|-------------|
| `npm run compile:circuits` | Compile `circuits/hello_hash.circom` to R1CS + WASM in `build/`. |
| `npm run setup:zk` | Generate ptau, zkey, and `contracts/verifiers/HelloHashVerifier.sol`. |
| `npm run compile` | Compile circuits, then `hardhat compile`. |
| `npm test` | Full pipeline: circuits → ZK setup → Hardhat compile → tests. |
| `npm run clean` | Remove `build/`, `cache/`, `artifacts/`, and generated verifier. Re-run `setup:zk` before testing. |

The first `npm test` runs trusted-setup generation and can take about a minute. Generated artifacts under `build/`, `cache/`, and `artifacts/` are gitignored.

Proof generation runs inside the Hardhat test (no separate script). Tests skip the ZK path if zkey/WASM are missing — run `npm test` once to produce them.

If setup or test generation fails, see [TROUBLESHOOTING.md](TROUBLESHOOTING.md) for common Circom, ZK artifact, and Hardhat compile fixes.

## Layout

| Path | Role |
|------|------|
| `circuits/hello_hash.circom` | Example circuit (opencircom Poseidon). |
| `scripts/compile_circuits.sh` | `circom … -l node_modules/opencircom/circuits` |
| `scripts/setup_zk.sh` | ptau, zkey, Solidity verifier export. |
| `contracts/verifiers/HelloHashVerifier.sol` | Groth16 verifier (regenerated by `setup:zk`). |
| `contracts/PoseidonProofGateway.sol` | Example gateway calling the verifier. |
| `test/hello.test.js` | Generates proof in-test; verifies via verifier + gateway. |
